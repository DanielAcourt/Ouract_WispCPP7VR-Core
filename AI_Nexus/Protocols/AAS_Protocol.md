# PROTOCOL: AGENCY ARBITRATION SCHEMA (AAS)

## Version: 1.1.0-BETA
## Classification: SSoT / Directive Level

### 1. MISSION STATEMENT
The AAS provides a formal, computational framework to resolve logical conflicts arising between the Conceptual Core (Identity), Theoretical Frameworks (Research), and Runtime Execution (C++). It acts as the "Symmetrical Guard" for multi-agent coordination, ensuring that agent intent never violates the physical or structural integrity of the Sovereign Framework.

### 2. CONFLICT RESOLUTION MATRIX (Precedence Rules)
| Conflict Type | Primary Authority | Arbitration Protocol |
| :--- | :--- | :--- |
| **Logic vs. Intent** | C++ Runtime | Physical constraint overrides conceptual intent. "The Vessel dictates the Soul's limits." |
| **Theory vs. Protocol** | Protocols/ (SOPs) | SOPs define the boundary of acceptable theory. "The Alchemist's Circle must be closed." |
| **Agent vs. Agent** | Strategist | Final arbiter for mission-critical directives and roadmap alignment. |
| **Research vs. Hardening** | Tactician | Implementation stability takes precedence during "Hard Freeze" or "Stabilization" cycles. |
| **Ambiguity vs. Action** | Researcher | If `Confidence_Score` < 0.7, execution must pause for a "Deep Planning" handshake. |

### 3. OPERATIONAL TRIGGERS (409 Conflict Gates)
AAS MUST be invoked if:
*   **Error Code 409:** Agency Conflict detected during PSTA telemetry or module handshake.
*   **Architectural Delta > 0.1:** A proposed change deviates from the "Sovereign Rule" or Level 0/1 core protocols.
*   **Multi-Agent Deadlock:** Two or more agents propose conflicting logic for the same structural node.
*   **Hallucination Detection:** An agent proposes a solution that contradicts documented `AI_Nexus/Memories/` or `Physical Truth`.

### 4. MANDATORY INTERFACE
Any module or agent report invoking an AAS check must include:
*   `Authority_ID`: The specific agent persona (Strategist, Tactician, Researcher) invoking the request.
*   `Confidence_Score`: A 0.0-1.0 float representing certainty.
*   `AAS_Route`: The specific escalation path utilized (see Section 5).
*   `Historical_Reference`: A path to the `AI_Nexus/` node used as the basis for the decision.

### 5. ARBITRATION ROUTES
*   **07-ALPHA (The High Path):** Direct escalation to the Technical Lead. Mandatory for all Level 0/1 (Architecture/Protocol) changes.
*   **07-BETA (The Peer Path):** Persona-based cross-verification. (e.g., Researcher proposes a math shift; Tactician must verify implementation feasibility).
*   **07-GAMMA (The Sovereign Path):** Autonomous resolution based strictly on the Resolution Matrix (Section 2). Only applicable to Level 2 (Identity) or lower tasks.
