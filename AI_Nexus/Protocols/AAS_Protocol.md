# PROTOCOL: AGENCY ARBITRATION SCHEMA (AAS)

## Version: 1.3.0-BETA (Tiered 07 Sync)
## Classification: SSoT / Directive Level

### 1. MISSION STATEMENT
The AAS provides a formal, computational framework to resolve logical conflicts arising between the Conceptual Core (Identity), Theoretical Frameworks (Research), and Runtime Execution (C++).

### 2. TIERED "07" SYNC PROTOCOL
To balance deterministic safety with "Speed of Action," the synchronization level is dictated by task complexity:

*   **TIER 1 - ALPHA (Complexity > 5):** Full 5-phase **Level Induction Protocol (LIP)**.
    1. Intent (Why), 2. Constraints (Where), 3. Arbitration (How), 4. Planning (Synthesis), 5. Handshake (Confirmation).
*   **TIER 2 - BETA (Complexity 3-5):** Abbreviated LIP.
    - Intent analysis + Phased Plan Generation + Salute.
*   **TIER 3 - GAMMA (Complexity < 3):** Direct Action.
    - Persona Identification + 07 Salute.

### 3. CONFLICT RESOLUTION MATRIX (Precedence Rules)
| Conflict Type | Primary Authority | Arbitration Protocol |
| :--- | :--- | :--- |
| **Logic vs. Intent** | C++ Runtime | Physical constraint overrides conceptual intent. |
| **Theory vs. Protocol** | Protocols/ (SOPs) | SOPs define the boundary of acceptable theory. |
| **Agent vs. Agent** | Strategist | Final arbiter for mission-critical roadmap alignment. |
| **Research vs. Hardening** | Tactician | Stability takes precedence during "Hard Freeze" cycles. |
| **Ambiguity vs. Action** | Researcher | If `Confidence_Score` < 0.7, execution MUST pause for a LIP re-sync. |

### 4. OPERATIONAL TRIGGERS (409 Conflict Gates)
AAS MUST be invoked if:
*   **Error Code 409:** Agency Conflict detected.
*   **Architectural Delta > 0.1:** Deviation from core protocols.
*   **Multi-Agent Deadlock:** Conflicting logical proposals.
*   **Hallucination Detection:** Contradicts documented `Memories/` or `Physical Truth`.

### 5. ARBITRATION ROUTES
*   **07-ALPHA (The High Path):** Direct escalation to the Technical Lead. Mandatory for Level 0/1 changes.
*   **07-BETA (The Peer Path):** Persona-based cross-verification.
*   **07-GAMMA (The Sovereign Path):** Autonomous resolution based on Section 3 matrix.
