# Milestone: Minimum Viable Soul (MVS) Checkpoint

## 🎯 The Objective
To reduce the **Lead's Cognitive Bandwidth** debt by focusing on a single, functional slice of the "Digital Museum" vision. This checkpoint transitions the framework from a theoretical research project into a functional MVP (Minimum Viable Product).

---

## 🏛️ MVS Definition: "The IIIF Lidar Artifact"
The MVS is reached when a single, high-fidelity Lidar-scanned object can be summoned, persisted, and interacted with using the Sovereign Framework.

### **Core Components:**
1.  **IIIF Integration:** Fetching object metadata and manifest data from a IIIF-compliant source.
2.  **Sovereign Spawning:** Using the `USovereignSpawnManager` to summon the object based on its IIIF identity.
3.  **Digital Twin Bridge:** Mapping IIIF metadata fields to the `Telemetry.` namespace on the actor.
4.  **Possession & Interaction:** A player (Wisp) can possess the object, causing a UI to display its historical metadata.
5.  **Black Box Persistence:** The state of the object (position, metadata modifications) survives a session restart via the Black Box protocol.

---

## 🚀 Impact on Roadmap
*   **Phase II (Data Survivability):** Currently nearing completion. This provides the "Hardened Body" for the MVS.
*   **Phase III (Lidar Intelligence):** This is where the MVS lives. By defining it as a "Single Object," we avoid the complexity of a full runtime mesh reconstruction system.
*   **Scaling:** Once one object is perfect, the foundation is laid to summon 100s of objects and integrate advanced features like Text-to-Speech engines.

---

## 📉 Debt Reduction Strategy
By locking in the MVS, we:
*   **Eliminate Paralysis:** No longer aiming for a "Perfect Museum," but for "One Perfect Artifact."
*   **Clarify Delegation:** Jules and Claude can focus on the plumbing required for this specific object, reducing the need for constant Lead guidance.
*   **Verification:** Success is binary—either the object spawns with metadata, or it doesn't.
