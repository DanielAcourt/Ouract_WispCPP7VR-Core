# Terminal: Pi4_OS (The Local Manager)

## 🏛️ 1. Overview
The **Pi4_OS** terminal serves as the local management and debugging interface for the Raspberry Pi hardware stack. It runs a full operating system environment for manual intervention and log analysis.

## 🛠️ 2. Hardware Profile
*   **Platform:** Raspberry Pi 4 Model B.
*   **OS:** Raspberry Pi OS (64-bit with Desktop Environment).
*   **Peripherals:** Local display and HID support for on-site troubleshooting.

## 📡 3. Sovereign Role
*   **Pillar Host:** Social (S) & Administrative (A).
*   **Function:** Human-Machine Interface (HMI) for the safety kernel.
*   **Monitoring:** Visualizes local sensor trends and provides the "Manual Clearance" flag for safety alarms.
*   **Bridge:** Secondary data logger and backup file-system authority for the Black Box logs.

---

## 🛡️ 4. Security Status
*   **Classification:** PROTECTED.
*   **User Authority:** Requires physical or VNC credential validation.
*   **SOP:** Acts as the "Human in the Loop" for Warning-level VSS states.
